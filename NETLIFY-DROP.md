# View the site with Netlify Drop

1. Download **we-pay-probate-netlify-drop.zip** from this branch. On its GitHub file page, click **Download raw file** (the download arrow). This is the finished site, not source code.
2. Open https://app.netlify.com/drop and sign in to Netlify if prompted.
3. Drag the ZIP onto the upload area. If Netlify asks for a folder, unzip it and drag the extracted folder instead. The folder should contain index.html directly, not another enclosing project folder.
4. Netlify will provide a separate address ending in netlify.app. Open that address to view the site.

This staging package contains the redesigned homepage, privacy page, custom 404 page, fonts, artwork, crawler files, and Netlify staging headers. Pages use noindex metadata and an X-Robots-Tag: noindex header. Analytics is disabled. No personal access token is needed for this browser upload.

Do not use the older we-pay-probate-netlify.zip; it does not contain the redesign. GitHub's green Code > Download ZIP button downloads the source project, which Netlify Drop does not build. Use the specific we-pay-probate-netlify-drop.zip file instead.

Keep this as a separate review site. Do not assign the live domain or change WordPress/DNS. Phone buttons open the device's phone app; a click is not proof of a connected call. The staging ZIP must be regenerated after source changes. For an approved production launch, review business facts and remove all staging indexing restrictions deliberately.
